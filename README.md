# Utkarsh Kulkarni — Portfolio Website

A sleek, modern developer portfolio engineered for a **Java Backend Engineer & Full-Stack Developer**. Built with **React 19**, **Vite**, and **Tailwind CSS v4**, featuring an interactive terminal, systems architecture breakdown, and featured engineering projects.

---

## ⚡ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 (Dark mode, cyber-glow accents, subtle grid backgrounds)
- **Icons:** Lucide Icons & Custom SVG brand glyphs
- **Typography:** Inter (Headings & Body), Fira Code (Monospace & Code blocks)

---

## 🚀 Key Sections

- **Terminal Simulation:** Live cURL-style interactive profile inspection with JSON output.
- **Featured Systems:**
  - **🧞‍♂️ GmailGenie AI:** Production-ready context-aware AI email response system with Chrome extension & Google Gemini backend.
  - **🚀 Taskflow REST API & Dashboard:** Full-stack task & project management application following strict layered patterns (Controller $\rightarrow$ Service $\rightarrow$ Repository $\rightarrow$ DTO $\rightarrow$ Mapper) with Jakarta Validation & MySQL.
  - **🧩 LeetCode Algorithm Vault:** Comprehensive repository of algorithmic solutions covering Graphs, DP, Trees, and Big-O optimizations.
- **Architecture & Engineering Principles:** Deep-dive cards explaining DTO isolation, zero-trust validation, failover pipelines, and HikariCP connection pooling.
- **Direct Recruiter Connect:** Instant 1-click email & phone copying, WhatsApp direct messaging, LinkedIn, and Instagram.

## 💻 Local Development

Clone the repository and run the local development server:

```bash
# Clone repository
git clone https://github.com/utkarshkulkarni45/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

The application will run at `http://localhost:5173/`.

---

## 📦 Production Build

```bash
npm run build
npm run preview
```
